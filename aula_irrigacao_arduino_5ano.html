Conceito da Atividade
SEÇÃO 01 · EMBASAMENTO

O que é Programação Criativa?

É usar a programação como ferramenta de expressão e resolução de problemas reais. O aluno deixa de ser consumidor de tecnologia e passa a ser criador — escrevendo instruções que fazem máquinas agirem.

O que é Arduino?

Uma plataforma de hardware e software livre que permite criar projetos eletrônicos interativos. O Arduino lê sensores do mundo físico e executa ações — como ligar uma bomba d'água.

A Proposta: Irrigação Automática

Os alunos construirão um sistema que mede a umidade do solo com um sensor e, automaticamente, aciona uma mini-bomba d'água quando a planta precisar ser regada. O projeto une eletrônica básica, lógica condicional (SE/ENTÃO) e consciência ambiental, conectando-se às ODS 2 (Fome Zero) e ODS 6 (Água Potável) da ONU.

BNCC / CT: EF05MA05 · Lógica CO · Abstração CO · Decomposição CO · Reconhecimento de Padrão CO · Algoritmo STEAM · Ciências · ODS 6

06

Exercitar o trabalho colaborativo e a comunicação ao apresentar o projeto para a turma, explicando as decisões tomadas.

Problematização Conexão com ODS
🧠
⏱ 10–25 MIN · AULA 1
Conceituação: Como o Arduino "pensa"?

Mini-aula dialogada (máx. 15 min) usando slides ou quadro:

  • Sensor de Umidade: duas hastes metálicas no solo — quanto mais úmido, mais corrente passa → valor analógico de 0 a 1023.
  • Condicional: SE (umidade < 400) ENTÃO liga bomba SENÃO desliga bomba.
  • Loop: o Arduino verifica o sensor a cada 5 segundos — repetição automática.
  • Distribuir a Ficha de Algoritmo (imprimível) para os alunos escreverem o pseudocódigo com palavras.
Aprendizagem Ativa Pseudocódigo Analogia SE/ENTÃO
🔌
⏱ 25–50 MIN · AULA 1
Mão na Massa: Montagem do Circuito

Grupos de 3–4 alunos recebem o kit e o Guia de Montagem Ilustrado:

  • Conectar o sensor de umidade ao pino A0 do Arduino e ao VCC/GND.
  • Conectar o módulo relé ao pino digital 7.
  • Conectar a mini-bomba 5V ao relé (circuito de carga).
  • Checar com o colega: "Está certo? O fio vermelho é VCC?" — estratégia de peer checking.
  • Professor circula, tira dúvidas, não dá a resposta pronta — faz perguntas guiadas.
Prototipagem Trabalho Colaborativo Peer Checking
💻
⏱ 0–30 MIN · AULA 2
Programação: Escrevendo o Código

Um aluno do grupo digita o código na IDE Arduino (ou Tinkercad Circuits online), enquanto os outros orientam:

irrigacao.ino · Arduino IDE C++ 
// ════════════════════════════════════
// Irrigação Automática · 5º Ano
// Profª Synthia Duarte · SDInformática
// ════════════════════════════════════

const int PINO_SENSOR = A0;   // sensor de umidade
const int PINO_RELE   = 7;    // controle da bomba
const int LIMITE      = 400;  // solo seco abaixo disto

void setup() {
  Serial.begin(9600);
  pinMode(PINO_RELE, OUTPUT);
  digitalWrite(PINO_RELE, HIGH); // bomba começa desligada
}

void loop() {
  int umidade = analogRead(PINO_SENSOR);

  Serial.print("Umidade: ");
  Serial.println(umidade);

  if (umidade < LIMITE) {
    // Solo SECO → liga a bomba
    digitalWrite(PINO_RELE, LOW);
    Serial.println("🌱 Regando...");
  } else {
    // Solo ÚMIDO → desliga a bomba
    digitalWrite(PINO_RELE, HIGH);
    Serial.println("✔ Solo úmido. OK!");
  }

  delay(5000); // verifica a cada 5 segundos
}
  • Fazer o upload para o Arduino e abrir o Monitor Serial.
  • Testar: mergulhar o sensor em água → observar o valor cair → bomba deve ligar!
Codificação Depuração Tinkercad (opcional)
🧪
⏱ 30–45 MIN · AULA 2
Teste, Erro e Ajuste (Debugging)

O erro faz parte! Orientações para os grupos:

  • Usar o Monitor Serial para ver os valores em tempo real.
  • Se a bomba não ligar: verificar o valor limite — é preciso ajustar o número 400?
  • Desafio extra: adicionar um LED verde (solo ok) e LED vermelho (solo seco).
  • Registrar as tentativas no Diário de Bordo Digital (ou caderno).
Depuração Iteração Desafio Extra

⏱ 45–60 MIN · AULA 2
Apresentação e Socialização

Cada grupo apresenta (2 min) respondendo:

  • "O que o nosso sistema faz?"
  • "Qual foi o maior desafio? Como resolvemos?"
  • "Como isso ajuda o meio ambiente?"

Professor medeia, valoriza o processo e destaca conexões com a realidade. Encerramento com reflexão: "O que mais você quer controlar com Arduino?"

Use o Tinkercad Circuits (gratuito, no navegador) — simula o sensor, o relé e a bomba virtualmente. Perfeito para laboratórios sem Arduino.

♿ Inclusão

Ofereça papéis diferenciados no grupo: quem digita o código, quem monta o circuito, quem observa e anota — todos contribuem de forma significativa.
