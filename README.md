# irrigacao-programacaocriativanarobotica
Desenvolver o pensamento computacional e científico por meio da construção de um sistema automatizado de irrigação para o 5º ano do Fundamental I.

A proposta é unir programação criativa + robótica + sustentabilidade.
Os alunos vão criar um sistema com Arduino Uno que “decide” quando uma planta precisa de água, usando um sensor de umidade do solo.

É aquela virada de chave: sair do “apertar botão” e ir pro “resolver problema real”.
